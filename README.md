# Traffic Stats API

## Описание

Это небольшое приложение, реализованное с использованием **Nest.js** и **TypeScript**, для эмуляции сбора и анализа данных о трафике. Приложение имеет один REST API endpoint для получения статистики о посещениях за последний час.

## Цель

Целью является показать умение работать с Node.js, TypeScript, фреймворком Nest.js, взаимодействовать с внешними API, обрабатывать данные и писать unit-тесты.

## Стек технологий

- **Язык программирования**: TypeScript
- **Фреймворк**: Nest.js
- **Тестирование**: Jest

## Установка и запуск

1. Клонируйте репозиторий:
    ```bash
    git clone <URL_репозитория>
    ```

2. Перейдите в каталог проекта:
    ```bash
    cd traffic-stats
    ```

3. создайте файл .env из env.example:
    ```bash
	задайте порт для переменной APP_PORT
    ```

4. Установите зависимости:
    ```bash
    npm install
    ```

5. Запустите приложение:
    ```bash
    npm run start
    ```

    Приложение будет доступно по адресу: `http://localhost:3000`.

6. Тестирование:
    ```bash
    npm run test
    ```

## API Endpoint

### `GET /traffic-stats`

Этот endpoint эмулирует получение данных о посещениях, фильтрует их по времени (за последний час) и возвращает суммарное количество посещений.

#### Пример ответа:

```json
{
  "totalVisits": 55
}
